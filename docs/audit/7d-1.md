# 7d-1: CV API, plus QA follow-ups on #46 (ADR-024)

Branch `feat/phase-7d-cv-api`, stacked on #46 (7c), which is stacked on #45
(7b). The Owner's 7d layout choice is a separate "CV" page; the screen follows
in 7d-2.

## What changed

* Routes (all need a session; every read and write is scoped to the account):
  * `GET /api/cv/versions`;
  * `POST /api/cv/originals`;
  * `POST /api/cv/analyses`;
  * `GET /api/cv/analyses/{id}`;
  * `PATCH /api/cv/suggestions/{id}`;
  * `GET /api/cv/analyses/{id}/preview`, which returns the sections, a line
    diff against the parent and the applied count;
  * `POST /api/cv/analyses/{id}/approve`, which returns the version and its
    diff.
* `CvError` is mapped:
  * `invalid_cv` → 400;
  * `cv_version_missing`, `cv_run_missing` and `cv_suggestion_missing` → 404;
  * `cv_nothing_accepted` and `cv_nothing_changed` → 409.
* Rate limit: `ratelimit.CV_RULE` (`cv.write`, 120 per 300 s per account) on
  the four write routes. Reads are not limited.
* QA n1 on #46: approving changes that leave the CV identical to its parent
  (for example an accepted, unedited flag) raises `cv_nothing_changed`
  instead of storing a copy.
* QA n2 on #46: migration 14 adds a partial unique index on tailored
  `(parent_version_id, target_type, target_id, content_sha256)`. Approval
  inserts with `ON CONFLICT DO NOTHING` and returns the winner's version when
  it loses a race.
* QA n3 on #46: a suggestion from a pruned run returns `404
  cv_suggestion_missing`, the signal for the screen to reload the latest run
  (tested).

## Cost and latency

* A decision is one rate-limit upsert plus one row update.
* A preview or approval reads the run, the version and the suggestions, then
  applies them in memory; an approval adds one insert.
* No LLM, no network (a test patches `socket.connect` to fail), no background
  job.

## Tests

* `tests/test_api_cv.py` (14):
  * session required on every route;
  * the full flow: original, analysis, decide, preview, approve, list;
  * the two 409 conflicts;
  * edit and undo;
  * body validation;
  * isolation between students;
  * the rate limit;
  * a pruned-run suggestion returns 404.
* `tests/test_cv_approval.py`: a concurrent identical approval returns the
  winner's version.
